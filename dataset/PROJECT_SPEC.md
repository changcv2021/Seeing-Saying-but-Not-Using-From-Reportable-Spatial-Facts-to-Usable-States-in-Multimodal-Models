# SpaceConflict Project Specification

SpaceConflict evaluates whether a multimodal model maintains a consistent partial spatiotemporal world. The core unit is `(media, supported_claim, contradictory_claim, certificate)`. An independent challenge contains `UNKNOWN` claims.

## Truth policy

- `SUPPORTED`: accessible source-grounded facts entail the claim.
- `CONTRADICTORY`: the same facts explicitly refute the claim or make it inconsistent.
- `UNKNOWN`: both the claim and its negation remain satisfiable.
- Absence of an edge is never a negative edge.
- `MODEL_PREDICTED` facts cannot be benchmark ground truth.
- Numeric distance, depth, speed, acceleration, displacement, size, angle, pose, duration, path length, and threshold-derived categories are excluded.

## Frozen construction order

Registry → source discovery → tiered acquisition → profiling → deterministic adapters → source reconstruction → world index → world-level split → partial world graphs → evidence subgraphs → claim graphs → typed edit → proof → language realization → graph-text-graph verification → independent verification → quota sampling → export.

## Release targets

- Core release: 10,000 auto-accepted minimal pairs: L1 2,000; L2 2,000; L3 3,500; L4 2,500.
- Unknown challenge: 2,000 claims, at least half generated by decisive-evidence ablation.
- At least 70% of contradictory claims preserve the predicate; `PREDICATE_COMPLEMENT` is at most 20%.
- Split isolation is by `global_world_id` and occurs before any language generation.
- Quality constraints override quota targets. Shortfalls are reported, never filled with unproved samples.

## Source-reference release policy

SpaceConflict does not redistribute source media. The release contains frozen source IDs and revisions, source-file hashes, deterministic adapters, graph edits, proof certificates, and local build scripts. End users acquire media from each upstream dataset and accept its terms independently. Unresolved upstream license conflicts therefore do not block internal construction, but they continue to block media redistribution and must remain disclosed in the dataset card.

The Chinese build guide adjacent to this repository is the normative design document. Versioned contracts and schemas in this repository turn it into executable constraints.
