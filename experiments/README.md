# Research experiments

Experiments are grouped by scientific purpose rather than development-stage numbers.

| Directory | Study |
|---|---|
| `spatial_world_state/` | Spatial fact reporting, state use, matched behavioral controls and bounded mechanism studies |
| `behavioral_closure/` | Source-grounded behavioral follow-up and held-out closure tools |
| `sequential_state/` | Composed state transitions, component controls and bounded internal interventions |
| `state_interventions/` | Follow-up state-selection, protection, reverse and success controls |

Versioned implementations and helper packages are retained for traceability. Cross-study imports point to functional paths. See [the migration map](../docs/LAYOUT.md) to interpret historical records.

Diagnostic inputs/gold, raw activations, checkpoints and per-sample responses are intentionally not distributed. These are research implementations, not independently runnable packaged experiments. Prepare legally sourced inputs and fresh protocol/engineering acceptance before running them. Directory cleanup performs no training, internal analysis or new inference, and establishes no new research findings.
